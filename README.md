# 问道：归舟

基于 0.086 后的公开可运行源码快照，默认在 HD-2D 场景中使用原作者提供的站姿和行走像素图，游泳、掌舵等保留现有专用动作，不含第三方 3D 主角模型。主菜单、游戏场景和存档功能保留。此仓库快照不是安装包，也不是新版本发布。

1. 安装 Godot 4.7.1 标准版。
2. 打开或导入 [godot/project.godot](godot/project.godot)。
3. 等资源导入完成后按 **F5** 运行项目，在主菜单选择「进入归舟」。

默认无需编译原生扩展，游戏会使用内置 GDScript 后端。F8 是性能面板；可设环境变量 `ARK_HD2D=0` 切换到不带 HD-2D 场景效果的原始像素呈现。保留了项目 [许可证](LICENSE) 和 [素材授权说明](ASSET_NOTICES.md)。

已验证 Linux 无头导入和主菜单进入；未验证 Windows 打包或实际画面。请备份原有存档后再测试。
