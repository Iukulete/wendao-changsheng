# 阮同尘｜portrait master v1

## 目标

为《问道长生》制作阮同尘的全身透明背景角色立绘，作为后续对话半身像与头像的母图。他是《终末契约》中的值夜契官与临时庭审理人，重点是夜勤、案卷、到期令和把责任拆成可复核的个人事项。

## 视觉规格

- 延续项目既有 `wendao_anime_mature_v2` 角色立绘风格：干净轮廓、细节克制、低饱和末法城色彩、柔和但有方向性的夜灯光。
- 自然修长偏高的成年男性比例，肩背挺直但不魁梧，站在案桌与封存证匣旁像一个长期处理复杂程序的人；不要 Q 版、不要大头娃娃、不要夸张反派姿势。
- 深黑长发束成利落低冠，鬓边有少量夜勤风尘，用暗铜簪与窄蓝带固定；发尾整洁中带连续值夜后的自然松散。
- 面容清瘦沉静，眼下有值夜审案的疲惫；读案卷时先看期限、当事人和证据缺口，签下保护令时坚定，发现措辞漏洞时眉心短暂收紧。
- 穿低饱和墨黑、雾蓝、旧米白与少量暗铜边的契法院夜勤官服：长身分层外袍、窄袖内衫、可翻阅卷宗的肩披、护腕、软底长靴与便携灯袋；胸前挂无可读文字的值夜木牌，腰侧分列到期印、封条筒、案号夹和三色责任标签。
- 一手持契法院到期印或无字止扣令副本，一手托按本人、机构、待核证据分开的案卷夹；旁边可见三人共启证匣与便携油灯。动作像正在把一桩大案拆成逐人可复核的步骤。

## 色彩与安全限制

- 整体低饱和，主色为墨黑、雾蓝、旧米白和暗铜；避免荧光色、鲜艳红和赛博高光。
- 年龄未完全确认，保持完整功能性官服，不使用裸露、内衣化或性感化构图；魅力来自克制、疲惫、秩序感和责任压力。
- 不加入其他人物、场景文字、UI、徽标或可读契约内容，不把印章上的纹样渲染成可读文字。

## 交付

输出一张透明背景 PNG 全身立绘，保留足够边缘空间，完整包含头发、衣摆与鞋子，方便自动生成对话 bust 与 avatar；优先保证修长成年比例、低冠、夜勤官服、到期印、分栏案卷和三人共启证匣稳定。
