# 罗素织｜portrait master v1

## 目标

为《问道长生》制作罗素织的全身透明背景角色立绘，作为后续对话半身像与头像的母图。她是《终末契约》中住进柳家旧屋的表妹，十年间修过屋顶，并把一半房屋租给修伞匠；柳鹤生恢复身份时，她最担心的不是表哥本人，而是系统会把身份变更自动执行成整户驱逐。角色重点是无过错现住者的居住安全、修缮支出和门契分案。

## 视觉规格

- 延续项目既有 `wendao_anime_mature_v2` 角色立绘风格：清晰轮廓、克制细节、低饱和归籍巷潮雾、旧屋木料和修伞线的柔和质感。
- 自然修长偏高的成年女性比例，肩背和前臂有十年修屋、搬瓦与照看住户的实用力量；站姿警惕而稳定，不缩成 Q 版、大头娃娃或柔弱受害者剪影。
- 深黑棕中长发编成利落低辫或低髻，用旧布带与木簪固定；发尾带潮雾、木屑和屋顶灰尘，不使用华丽发饰。
- 面容清醒、戒备而不刻薄，手里握着门契时先看能否保护三户住处；说“你不赶，系统会替你赶”时是对机器后果的准确判断，不是对亲人的敌意。
- 穿低饱和雾蓝、旧米白、灰棕、煤灰和少量暗青的归籍巷修屋工层衣：完整不透明高领内衫、短防潮外套、分层围裙、耐磨长裤、护膝与防滑软底靴，衣物有雨水、木屑、旧瓦灰和反复修补痕迹。
- 一手持旧屋门契封套与木尺，一手托修缮账板或临时居住保护扣；腰侧挂修屋钳、麻绳、租金回执夹和一枚无字铜钥匙，所有纸页只呈现抽象线条。

## 色彩与安全限制

- 整体低饱和，主色为雾蓝、旧米白、灰棕、煤灰、暗青和少量旧铜；避免荧光色、鲜艳红、塑料高光和豪宅式金饰。
- 年龄未完全确认，保持完整修屋工装和居住者主体性；不使用裸露、内衣化或性感化构图。
- 门契、租金回执、修缮账和保护扣不得出现可读文字、UI、徽标或水印；不加入其他人物和复杂场景。

## 交付

输出一张透明背景 PNG 全身立绘，保留足够边缘空间，完整包含头发、外套、双脚软底靴、门契封套、木尺、修缮账板、保护扣和工具，方便自动生成对话 bust 与 avatar；优先保证修长成年比例、十年修屋劳动痕迹、三户居住保护和“身份纠正不等于自动赶人”的剧情锚点稳定。
