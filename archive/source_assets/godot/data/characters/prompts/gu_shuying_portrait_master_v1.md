# 顾疏萤｜portrait master v1

## 目标

为《问道长生》制作顾疏萤的全身透明背景角色立绘，作为后续对话半身像与头像的母图。她是静息室中被当作“唯一受益人”的成年患者，设计重点是保留主体性、沟通辅助与辨药者的记忆，不把病后虚弱处理成装饰。

## 视觉规格

- 延续项目既有 `wendao_anime_mature_v2` 角色立绘风格：干净轮廓、克制细节、低饱和雾蓝病房色彩、柔和而有方向性的光。
- 修长的成年比例与病后自然消瘦体态，肩背由软枕和轻支具支持；手指保持敲击床沿的准确性，姿态真实、安静、有边界。
- 墨黑长发夹少量冷灰发丝，低松束在肩后，发尾有长期卧床与反复护理留下的自然散乱；耳侧可有一枚旧药草木片作为年轻时教辨药的记忆锚点。
- 面容清瘦、眼神清醒时有辨药者的专注；听到熟悉声音有细微回应，困惑时眉心收紧，明确拒绝时目光稳定。
- 穿低饱和雾蓝、灰白与墨灰的静息室分层病房服：保暖高领、宽松长衫、披肩、宽腿裤或床边裙摆、无硬饰软底鞋；衣物有清洗和药渍痕迹。
- 携带四格眼动沟通板、无字图示牌、床边木质节拍块、旧药草木片和低亮脉象计时灯；封存记录只作为卷起的道具，不显示可读文字。
- 可采用站立扶持或床边坐姿的全身构图，表现她用五下敲击说“停、再测、不要硬接”；透明背景、完整头发和鞋子、不裁切。

## 色彩与安全限制

- 整体低饱和，避免荧光蓝、过强高光和鲜艳赛博色；冷灰、雾蓝、米白为主，药草绿只作极小记忆点。
- 角色魅力来自清醒表达、专业记忆与主体性，不使用裸露、内衣化或性感化构图。
- 不加入其他人物、场景文字、UI、徽标或可读病历内容。

## 交付

输出一张透明背景 PNG 全身立绘，保留足够边缘空间，方便自动生成对话 bust 与 avatar；优先保证修长成人比例、低束长发、分层病房服、沟通板和敲击道具稳定。
