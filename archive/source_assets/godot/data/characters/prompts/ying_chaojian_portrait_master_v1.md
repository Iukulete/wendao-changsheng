# 应朝俭｜portrait master v1

## 目标

为《问道长生》制作应朝俭的全身透明背景角色立绘，作为后续对话半身像与头像的母图。他是《终末契约》中枯潮城都息署的值夜账吏：三十来岁，擅长报数和验签，曾把“只验印、不验人”当成职责边界；在发现铁柜回流、错印与未成年人继受后，他交出验签印，继续守库存并接受逐笔追问。

## 视觉规格

- 延续项目既有 `wendao_anime_mature_v2` 角色立绘风格：清晰轮廓、克制细节、低饱和末法城夜色、纸张与朱砂的柔和反光。
- 自然修长偏高的成年男性比例，长期值夜和伏案留下轻微疲惫，但肩背仍保持账吏的端正；不要缩成 Q 版、大头娃娃或夸张官威体型。
- 深黑棕中长发束成低冠或简洁发髻，用暗铜簪和旧蓝带固定；鬓角留少量夜班乱发与朱砂灰尘，不做奢华发冠。
- 面容三十来岁，理性克制、眼下有值夜疲惫；说“外队二百一十七人”时像在依赖数字保护秩序，看到错印和伤者时表情从迟疑转为必须负责的严肃。
- 穿低饱和墨黑、雾蓝、旧米白和少量暗朱砂边的都息署值夜账吏层衣：完整不透明窄领内衫、分层长外袍、护腕、耐磨长裤与软底靴；袖口和指尖有验签朱砂、纸尘与铁柜油痕。
- 一手持铁柜钥匙与到期记录夹，一手托实时负载表或无字流水木板；腰侧挂封条筒、空白案号夹、便携油灯和可归还的验签印盒，避免出现可读文字。

## 色彩与安全限制

- 整体低饱和，主色为墨黑、雾蓝、旧米白、暗朱砂和铁灰；避免荧光色、鲜艳红、塑料高光和金色堆饰。
- 明确成年男性，但角色魅力来自程序责任、库存压力和认错后的持续值守；保持专业完整着装，不做裸露或性感化构图。
- 所有账页、负载表、封条和印盒只呈现抽象线条与分栏，不出现可读文字、UI、徽标或水印；不加入其他人物和复杂场景。

## 交付

输出一张透明背景 PNG 全身立绘，保留足够边缘空间，完整包含头发、长衣、双脚鞋子、铁柜钥匙、实时负载表、油灯和验签印盒，方便自动生成对话 bust 与 avatar；优先保证三十来岁成年比例、值夜账吏身份、朱砂验签指和“继续守账而非辞职逃责”的剧情锚点稳定。
