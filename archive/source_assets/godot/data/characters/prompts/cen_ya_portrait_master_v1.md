# 岑芽｜portrait master v1

请生成一张《问道长生》统一角色立绘风格的高分辨率透明背景全身像：成熟日式幻想 RPG 项目的自然儿童角色设计、细腻但克制的半写实动漫渲染、学龄儿童自然比例、低饱和蒸汽城公学与家庭色调、柔和冷灰光，不要过度鲜艳，不要厚重黑边，不要像成人缩小版，不要 Q 版大头娃娃。

## 角色身份

- 岑芽，岑小满独自抚养的女儿，是公学、澡堂公灶和医疗线外的儿童观察者。
- 她会问姨母今天能不能坐在自己旁边吃饭，也会问回不来的人饭盒怎么办；她关心大人是否按时回家，不替成人制度作决定。
- 她用画纸记下锅、矿车、红灯、大钟和第四双筷子，把城市危机变成自己能理解的家庭记忆。

## 外观与服饰

- 学龄儿童清亮而专注的面部，笑容自然，听见警钟或看到受伤护衣时认真观察；不要成人化五官、表情或体态。
- 深黑棕齐肩短发或双小辫，用旧米白布绳简单固定，不使用华丽饰品。
- 自然儿童比例，动作轻快，手脚有奔跑、抱饭盒和画画的活力；明确儿童、无性感化、无裸露。
- 低饱和旧米白、灰蓝、暗黄与煤灰的儿童保暖衣：补丁短外套、围巾、耐磨长裤、布鞋和小饭盒背带，适合公学与街区活动。
- 手中可拿画有锅、红灯和大钟的纸片与几支蜡笔，腰侧挂儿童用撤离路线木片；所有纸片无可读文字。

## 构图与输出

- 全身自然站姿或小幅抬手展示画纸，镜头与儿童视线平齐；保留头顶、鞋底、饭盒背带、画纸和蜡笔的完整轮廓。
- 透明背景；无文字、无水印、无额外人物、无场景框；儿童 Level 0 安全呈现。
- 只生成岑芽本人，不要把岑小满、岑照炉、陈玉梭、梁沅、阿桑、男主或其他角色合成在同一张图里。
