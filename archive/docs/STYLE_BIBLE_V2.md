# Style Bible v2：角色与战斗资产

两张用户提供的参考图只作为渲染和完成度锚点，不复制参考角色的身份、发型或服装。统一抽取：精致成熟的二次元脸、干净的局部线、分束头发、清楚的服装层级、修长成年比例、可读的材质和强剪影。

## 生产顺序

`剧情/运行时抽取 → 身份卡 → Portrait Master → 身份门 → 对话半身/头像 → 剧情需要的服装 → Combat Spec → 像素战斗 → Godot绑定 → 批次提交`

先锁身份，再锁画风，再派生动作。立绘没有通过身份门时，不生成半身像和像素战斗图。

## 统一视觉门

- 立绘全身、透明背景、1024×1536，四周约9%安全边距。
- 参考图的脸部信息、头发分层和材质完成度保留；全项目饱和度下调约25%–35%，特效亮度和Bloom控制在低档。
- 成人默认7.4–8.2头身；男主保持兜帽遮眼、黑青织锦、轮回玉和孤独侧背剪影。
- 儿童、巨汉和异形使用独立体型/身体计划，不能用成人图缩放或横向拉伸。
- 每个角色必须有脸型、发型结构、身体比例、职业剪影、服装层级、核心道具、姿态和色板锚点。

## 性格决定呈现尺度

`presentation_level` 分为0–3：0为功能性，1为成年魅力，2为明显但不露骨的商业游戏卖点，3为明确成年且剧情合理的特殊服装。尺度属于角色和具体服装字段，不能靠临时提示词猜测；服装等级不得超过角色上限。

未成年、年龄不明、年龄未确认角色硬性为0档。允许成人角色有露肩、锁骨、上胸曲线、侧腰、露背、高开衩等不透明商业游戏设计，但禁止露骨裸体、透明私密区域、性行为或色情动作。像素呼吸是肩、胸廓、腰带和衣料整体1–2像素的微动，不做单独胸部反复弹动。

## 像素与怪物

非战斗NPC不做Combat Core；普通敌人约16–20帧，精英20–28帧，玩家/高频队友28–40帧，Boss24–48帧。动作必须写明预备、命中、停顿、收招和技能事件，不以统一16帧代替设计。

怪物按 `族群 → body_plan → 质量级 → 战斗职责 → 独特器官 → 变体` 排队。每只正式怪至少一个主要和一个次要独特器官；同族变体至少改变两项结构或攻击语言，单纯换颜色不算新怪。每批6–8只并混合人形、四足、浮游/无定形和特殊体型。

详细字段和自动门见 `godot/data/art/style_bible_v2.json`、`godot/data/characters/art_production_queue_v2.json` 与 `godot/data/monsters/monster_production_queue_v2.json`。
