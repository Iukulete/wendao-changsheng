# 第一批剧情角色主立绘提示词

这批是“身份母版”，不是最终对话胸像或战斗帧。统一使用低饱和、修长成人比例、透明背景、无文字、单人全身、可切成头像/胸像/像素参考的成熟东方幻想角色设计。所有服装保持不透明；卖肉只通过剪裁、肩颈、腰线、姿态和场景气质表达，不出现性行为、露骨生殖器官或未成年化体态。

统一尾缀：

```text
mature anime fantasy character design, low-saturation palette, long-limbed adult proportions, full body, three-quarter standing pose, clean silhouette, transparent background, soft controlled lighting, restrained contrast, readable face and hands, no text, no logo, no extra characters, no cropped limbs, opaque costume, commercial game character sheet quality
```

## 批量验收

每张图先检查：

- 是否一眼能区分脸型、肩宽、发型结构、职业剪影和核心道具；
- 是否低饱和，且仍能看清脸、手和服装层次；
- 是否保持修长成人比例，避免大头、短腿、幼态、Q 版化；
- 成人向造型是否只出现在明确成年角色，并保持不透明、非露骨；
- 是否能裁成全身主立绘、对话胸像和头像，而不切掉核心道具；
- 是否没有文字、水印、额外人物、重复肢体和背景杂物。
