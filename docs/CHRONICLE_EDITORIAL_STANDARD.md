# 长卷逐段审校标准

六部纪元长卷的字数门槛不能替代编辑判断。正文禁止使用脚本拼接、模板换词、占位扩写或复用他作语句；自动工具只检查计数、结构和重复，不能签署内容通过。

## 段落去留

每段至少完成一件可指出的事：带来新的可观察事实，让人物采取动作或说出只属于她的话，改变冲突条件，兑现前文伏笔，或留下后章能够读取的后果。只重复气氛、主题、紧迫性或上一段结论的段落应删除或重写。

作者提交每章前，必须逐段回答三个问题：本段让人物、局势或读者认知发生了什么变化；为什么变化必须发生在这个位置；删掉本段会损失哪条因果、哪次人物判断或哪项可玩的后果。三个问题都答不出的段落不进入正文。这里的“逐段”不允许抽样，也不允许用统一评语批量签署。

JSON 中的 `description_blocks` 与 `outcome_blocks` 只用于逐项保存人工写好的续接段落。运行时只按原顺序用空行连接，不改写、不替换、不补句；每一项仍按独立段落接受作者与非作者审校。

短对白和短动作段可以保留，前提是它改变节奏、关系或现场判断。长段应在人物目标、空间位置、时间或行动阶段发生变化时自然分开，不能为了通过长度检查机械切段。

## 场景与人物

- 先写人在哪里、正在处理什么、手边有什么，再让设定进入场景。
- 数字、器物、伤势和资源必须参与因果，不能只作“具体感”装饰。
- 同一事实不由旁白、角色和结果页连续解释三次。
- 主要人物的措辞、回避方式和决断习惯必须可区分，删去名字后仍应大致认得说话者。
- 旁白少替玩家总结“必须、需要、真正、不是……而是……”，优先展示时限、缺口、拒绝和实际代价。

## 选择与后果

- 三个选择必须是当下可执行的不同动作，不是同一句价值判断换三个说法。
- 结果从玩家刚做的动作开始，写清执行过程、受益者、受损者、资源来源或用途，以及没有解决的部分。
- 扣除气血必须留下具体伤势；增加或花费灵石、丹药必须交代来源或去向。
- 每章至少有一条人物关系变化，并让足够多的选择写入可被后章读取的旗标、承诺、债务或延迟回声。
- 路线变体必须回答上一章的具体选择，不能只把路线名放进一段通用文字。
- 下一世首章使用三段分别创作的继承正文，承接上一世真实结局，不由运行时代写泛化回忆。

## 换线与资源可达

- 玩家每章都能改选三条路线。`route_variants` 只证明上一章最后一次选择，公共正文和本章选择不得假定玩家更早一直走同一路线。
- 人物、伤势、钥匙、设备、人数、款项和既成流程只能在所有来路共有时直接引用。若本章结果确实因上一章路线而不同，choice 必须提供覆盖三条来路的 `outcome_variants`，同时保留默认 `outcome` 作为安全兜底。
- 完卷摘要服从终章的真实选择；累计路线分只作生涯统计，不能把玩家刚看到的结局改写成另一条路线。
- 六卷资源测试从正常新档的 10 灵石、0 丹药开始，并按主界面真实顺序结算。任一可达余额在下一章都必须至少有一个可选行动；公共基金、机构库存或集体劳力承担的费用不得伪装成玩家个人扣款。
- 承诺和债务的关闭操作必须引用更早章节建立的 ID。运行时允许在该记录不存在时跳过，因此正文也不得无条件宣称一笔从未发生的旧账已经偿清。

## 交叉审校

一卷完稿后必须由未参与该卷初稿的人从第一段读到最后一段，并直接重写问题处。审校顺序为：事件连续性、人物动机、段落独立作用、对白辨识度、选择与结果因果、跨章伏笔回收、重复句式、数据字段与正文一致性。只有作者复核、交叉审校、质量门禁和实机阅读滚动全部通过，才可计入最终字数。

每卷必须在 `CHRONICLE_REVIEW_LEDGER.md` 留下初稿范围、作者复核范围、非作者交叉审校范围、重写记录和实机阅读结果。自动检查只能提供问题线索；无署名的“已检查”、只报字数或只报脚本通过，均不构成内容验收。
