# 当前产品目标：《问道：归舟》

唯一活跃产品是开放世界中的移动仙舟家园：自由探索、模板与逐件建造、
居民自主生活、庇护与共同成长。入口为 `ark_greybox.tscn`，默认菜单只服务
这套 3D 原型。旧卡片战斗和六纪元 UI 已退休，不作为新玩法设计基础。

## 近期优先级

1. 可靠建造与布置：位置、朝向、通路、材料账、拆回和存档一致。
2. 模板、舱室用途与真实床位容量；居民看得见地使用家园设施。
3. 居民独立采集、修理、休息和共餐，资源有实际来源。
4. 连续地形、探索成长与可绕行/撤退的危险；保留行动战斗方向。
5. 一处海岸、一段甲板、一间居室的统一正式视觉样板，再逐步扩区。

现有海域、低模人物、海面和时段控制是原型，不冒充最终大世界与最终美术。
餐饮等生活内容逐项设计，不一次堆满。修为、多层船舱、多船社会是后续方向。

## 内容保留与复用

旧剧情和人物资料按原字节、稳定 ID 与来源保存在 `archive/source_assets`。
它们是待审阅源资产，不自动导入首岛或当前居民；只有时代、地点、人物事实
和后果一致、权利清晰的内容才进入独立新呈现层。旧卡片参数和回合制流程
不是当前行动战斗的验收标准。

以 `OPENING_SLICE_DESIGN_V1.md`、`GAME_DESIGN_OPEN_WORLD_ARK_V1.md` 与实际
新原型测试共同核对功能；历史设计见 `archive/docs`，不再覆盖当前方向。
