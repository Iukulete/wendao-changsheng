# 《问道：归舟》角色模型生产规格 v1

> 状态：美术方向与技术验收草案。概念图不等于模型，也不代表已选定正式角色；所有人物均按明确成年角色设计。

## 视觉方向

- 当前近期优先级已调整：先让连续 3D 空间、建造与居民生活循环成立，再进入角色美术生产。用户指出此前像素 Sprite3D 看起来像平面贴片，因此它不再作为运行时角色本体或既定方向；当前灰盒改用可见头部、躯干、四肢的简单体积模型验证尺度和空间关系。
- 最终比例与制作方式尚未锁定。后续可评估风旅式斗篷轮廓、精致 Q 版/小比例 3D 等候选；可借鉴《八方旅人》的暖冷光影层次，但不据此认定采用 2D 像素角色，也不复制其角色、素材、动作、具体构图或配色。
- 候选比例约 2.5–3 头身，以有体积的头部、躯干、自然五官及有层次的发型服装验证；3D 场景可运用暖色局部光、冷色环境光、薄雾与适度景深。风格借鉴仅描述技术与观感，不复制《八方旅人》或其他作品的角色、素材、动作帧、具体构图和配色组合。
- 不以像素贴片作为既定运行时角色；统一验收轮廓、明暗、五官比例、服装辨识度与远景可读性，避免僵硬假脸或用低清素材掩饰粗糙。
- 角色需同时适应探索第三人称镜头和仙舟室内近景：远看轮廓/职业读得出，近看能看到自然表情、发饰、衣料和动作意图。面部避免写实皮肤、夸张玻璃眼、僵硬假笑与不自然五官排列。
- 女性居民人数可以多于男性，但脸型、体态、年龄感、肤色、身高、发型和职业轮廓不能模板化。服饰性感度属于角色衣橱与个人选择，不是女性角色的统一规定；低领礼装须成熟、优雅、可穿着，不做内衣化设计。

## 同一角色的成长衣橱

服装成长仍沿用同一成年角色的三阶段原则，但旧写实比例概念图已被新 3D 小人方向取代，不可作为模型比例或面部标准：

1. **漂泊期**：耐磨、能修补、便于劳动的多层布衣、绳结和旧靴；质感来自缝补与长期使用，不靠破烂裸露。
2. **富足期**：丝绸、织锦、精细剪裁、首饰与可选低领礼装；服装体现玩家积累和角色审美，不意味着角色身份/人格被财富替换。
3. **现代/近未来混搭**：可作为跨时代遗迹、异界居民或个人衣橱内容；服装有来源解释，避免把现代元素无缘无故撒在所有 NPC 身上。

图像仅是形状与材质参考；实际服装需重新设计为可动网格，并处理遮挡、坐姿、吃饭、工作和布料穿插。

## 模型与动画实现

- 灰盒阶段以程序化几何体或合规开源低模验证角色高度、转向、碰撞、遮挡、居所使用与多人空间，不投资正式角色贴图或动画。正式角色实现方式待候选素材与实机效果评审后决定。
- 角色图按头发、脸、上衣、下装、鞋、饰品和职业道具拆分图层或复用调色板，保持稳定角色 ID、碰撞体和存档引用。帧序列、方向和装备变体使用显式 manifest，不能靠运行时猜测文件名。
- 首个正式样板是一名成年女性居民：先验证 3D 镜头下的头部辨识、八向走路、转身、坐下/端碗/修理的动作表达、受风雨反应和三阶段换装。通过审美与技术门禁后再扩展居民；同一 sprite 只换色不算不同角色。
- 关键居民需要基础表情与眼神方向、眨眼、头发次级摆动和可读待机动作；普通居民可降低面部/次级运动成本，但不能用全员同脸同动作充数。
- 初始技术预算建议：常驻主角/关键居民以约 25k–45k 三角面、2K 纹理为起点；远景居民使用低模/共享材质与 LOD。最终预算以目标硬件帧率和 Godot 实机剖析调整，不以单个面数指标替代观感验收。

## 发布美术门禁

候选模型加入游戏前必须逐项记录：来源与授权、原始文件校验、骨架/动作兼容、网格与蒙皮检查、面部近景、服装穿插、灯光下材质、LOD/性能，以及是否符合角色年龄与设定。开放模型可用于灰盒或改造起点，但未经过视觉审查的素材不能直接变成正式居民。

当前主角与守潮人使用脚本拼装的简单 3D 几何灰盒，用于验证体积、人物占地及居所尺度，不代表最终 Q 版造型，也没有进入正式美术生产。此前生成的 2D 贴片仅为已否决的视觉试验，不作为角色资产标准。
