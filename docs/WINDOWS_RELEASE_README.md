# 《问道：归舟》Windows 原型

完整解压到可写的 D 盘目录，运行 `wendao-changsheng.exe`（沿用历史文件名）。
当前入口仅是3D仙舟家园，不再提供旧六纪元或卡片战斗。

建议窗口至少1280×720。WASD行走/游泳，Shift地面快跑，Space跳跃，E互动/掌舵，Q近身攻击，
B建造，F编辑附近储物箱/工作台，编辑中R旋转，M地图，F5保存。
建造时鼠标左键确认、右键/Esc取消。非编辑状态R/T是原型天气/时段控制。

存档沿用原型 `res://../.local/save/ark_greybox_v1.json` 解析位置。
移动或升级前备份对应 `.local/save`（包括主档、备份与隔离坏档），不要
假设它与历史六纪元的 `save/` 通用；没有自动旧进度转换或重置按钮。
提示“临时试玩/不会保存”时先保留旧文件，用匹配版本检查，不反复覆盖。

当前仍是灰盒/占位美术原型。发布包只含实际活跃资源及字体/AGPL许可，
不含旧剧情库、旧立绘/音源、测试、引擎下载或个人存档。
